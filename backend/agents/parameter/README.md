# FreeGen Parameter Checking Agent

This module implements the Parameter Checking & Interactive Dialogue Agent for the FreeGen project. It identifies requested CAD geometric shapes, determines missing required parameters dynamically based on JSON configurations, extracts parameters from natural language input, and leverages the Groq Cloud API to interactively prompt the user for any missing parameters until the requirement is met.

## Project Architecture

This module follows clean architecture and SOLID principles:
- **Routes (`routes.py`)**: Thin REST controllers that handle HTTP requests/responses and delegate to business logic.
- **Session Manager (`session.py`)**: In-memory state storage for ongoing parameter collection dialogues.
- **Extractor (`extractor.py`)**: NLP/Regex layer that identifies requested shapes and extracts provided dimension values.
- **Checker (`checker.py`)**: Validation layer that dynamically loads shape requirements and computes missing parameters.
- **Dialogue (`dialogue.py`)**: The integration layer with Groq to dynamically generate conversational prompts for missing parameters.
- **Schemas (`schemas.py`)**: Pydantic models to strictly enforce type checking on all API payloads.

## Requirements

- Python 3.12
- FastAPI
- Uvicorn
- Pydantic
- Groq Python SDK
- python-dotenv

## Installation

1. Navigate to the module directory:
   ```bash
   cd backend/agents/parameter
   ```
2. Create and activate a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install fastapi uvicorn pydantic groq python-dotenv
   ```

## Configuration

1. Create a `.env` file in the `backend/agents/parameter` directory:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```

## Running FastAPI

Since this is a module within the `backend` package, it uses relative imports. You must run the server from the root of the project (e.g., `d:\FreeCadAgent\freegen`).

To start the backend server locally, run:

```bash
uvicorn backend.agents.parameter.main:app --reload
```

The service will run at `http://127.0.0.1:8000`. You can access the interactive Swagger documentation at `http://127.0.0.1:8000/docs`.

## Example API Calls

### 1. Start a Session

**Request:**
```http
POST /start
Content-Type: application/json

{
    "message": "Create a cylinder"
}
```

**Response (Waiting):**
```json
{
    "session_id": "a1b2c3d4-e5f6-7890-abcd-1234567890ab",
    "reply": "What radius would you like?",
    "status": "waiting"
}
```

*(Note: "reply" is dynamically generated by the Groq API)*

### 2. Continue a Session

**Request:**
```http
POST /continue
Content-Type: application/json

{
    "session_id": "a1b2c3d4-e5f6-7890-abcd-1234567890ab",
    "message": "20 mm"
}
```

**Response (Complete):**
```json
{
    "status": "complete",
    "shape": "cylinder",
    "parameters": {
        "radius": "20 mm",
        "height": "50 mm" 
    }
}
```
*(If more parameters are missing, it will return another `"status": "waiting"` response instead)*
